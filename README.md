## Knights

**Knights** is a chess interface for KDE. It supports playing against computer engines (like GNU Chess), online chess servers, and human opponents. It features a clean, configurable interface with themes, animations, and full KDE integration.

---

## About This Package

This is an **Aurelis Linux** package built as an AppImage. It bundles all dependencies and runs on any Linux distribution without installation — including older distros and musl-based ones (Alpine, Void, etc.).

You can also run it as a regular AppImage on any Linux system: just make it executable and run.

```bash
chmod +x Knights-*.AppImage
./Knights-*.AppImage
```
